Code Examples

Common CSS patterns and how to use them in your HTML.

Button Usage

<button class="button">Primary Button</button>
<button class="button button--secondary">Secondary Button</button>

Hero Banner Usage

<div class="hero-banner">
    <div class="hero-content">
        <div class="hero-text">
            <h1>Title</h1>
            <p>Description</p>
        </div>
        <div class="hero-image"><img src="..." /></div>
    </div>
</div>

Section with Subsections

<div class="section">
    <div class="sub-section">
        <h3>Title</h3>
        <p>Content</p>
    </div>
    <!-- repeat for more subsections -->
</div>

Responsive Breakpoints

The CSS includes responsive design rules for different screen sizes:

📱 Mobile

Max Width: 768px

Single-column layouts, stacked content, optimized touch targets, larger fonts

📱 Tablet

768px - 968px

Two-column layouts, adjusted spacing, flexible imagery

🖥️ Desktop

968px+

Full three-column layouts, side-by-side content, maximum content width at 1440px
